# 按需持久化（Persistence）

只在用户明确要求保存、项目已有用户指定的认知载体且本轮内容确需续接，或用户明确启动跨会话认知寻路时加载。调用认知四象限、模式切换或提出“可以保存”的建议，都不等于写入授权。

## 共用规则

- 优先更新已有载体，遵守项目文档规则，不创建内容重复的认知笔记、复盘文件或交接副本。
- 没有授权或合适载体时，完整输出在对话中并声明未持久化。
- 写入时区分用户决定、已验证事实、材料声明、推断、假设和暂定选择，不把推断写成事实。
- 不持久化密钥、令牌、密码、个人隐私、财务明细或与续接无关的敏感内容；必要信息先脱敏。
- 用户可随时指定“这段记进去”或“这条别记”。

## 项目笔记本

仅在用户选择项目笔记本时建立。它是认知四象限产生的思考容器，不是交付物、项目主文档或框架文件。

- **位置：** 项目文件夹内，一个项目一个 `认知笔记-<主题>.md`；不放在 Skill 文件夹或隐藏目录。
- **当前状态索引：** 顶部固定五行——核心目标 / 已确认决定 / 开放风险 / 认知雾区 / 下一轮入口。每轮根据最新模式产物更新；没有内容时写“无”或“待确认”，不臆造。
- **历史记录：** 下方按模式追加，只增不改。每个记录块使用统一固定头：模式 / 日期 / 本轮目标 / 结论状态 / 下一轮入口；正文复用该模式的产物结构，不保留空栏目。
- **记录范围：** 保留模式产物、被否决选项和开放问题；原始材料只留必要依据摘要，不贴全文。敏感内容和与续接无关的探索噪声不进入记录。
- **读取成本：** 新会话先读顶部五行；只有发生冲突、需要追溯理由或用户要求回看时才读取历史记录。

## 与项目主文档的关系

- 笔记本只读项目主文档获取材料，不自动写回主文档。
- 来自主文档但未独立核实的内容标为 `[材料声明]`，不升级为用户决定或事实。
- 用户带入新版主文档或说明主文档已变更时，再检查冲突；旧记录标记 `[已被 <主文档> 覆盖]`，不删除历史。

## 与认知寻路的关系

大问题进入持久化认知寻路后，用认知地图取代通用项目笔记本，二者不同时追加。若从项目笔记本升级，地图注明承接来源，旧笔记本停止追加但不删除。
